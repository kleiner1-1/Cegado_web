# Legado-Bot Store — Vercel

Tienda Next.js de Legado-Bot con una estética premium inspirada en plataformas digitales modernas: fondo negro, alto contraste, acentos rojos, tarjetas, navegación compacta, hero visual, carrito, checkout, FAQ y diseño responsive.

## Contenido
- Marca y recursos proporcionados para Legado-Bot.
- Créditos: 20+40 ($8), 50+100 ($15), 100+250 ($25), 200+300 ($40).
- Planes: 3 días ($10), 7 días ($20), 15 días ($32), 30 días ($50).
- Métodos mostrados: Binance Pay, Nequi y Bre-B.
- Carrito y checkout de demostración preparados para conectar un backend real.

## Deploy en Vercel
1. Sube este proyecto a GitHub.
2. En Vercel selecciona el repositorio.
3. Framework: Next.js.
4. No hay variables de entorno requeridas para la plantilla visual.

## Pagos reales
El checkout actual es una interfaz preparada: no simula confirmaciones de pago. Para automatizar Binance Pay, Nequi/Bre-B y la entrega de créditos/planes al usuario de Telegram hay que conectar un backend, verificar el pago mediante el proveedor correspondiente y después llamar a la lógica de tu bot.
